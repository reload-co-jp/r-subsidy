# 補助金ニュース記事化

過去1週間の補助金関連プレスリリース・ニュースを検索し、`data/source/subsidy-news.json` に記事として追加する。

## 実行手順

1. **ニュース検索**（WebSearch）
   以下クエリで直近7日以内の記事を検索:
   - `補助金 プレスリリース 2026`
   - `中小企業 補助金 新設 2026`
   - `IT導入補助金 ものづくり補助金 最新情報`
   - `補助金 申請受付 開始 2026`
   - `中小企業庁 補助金 お知らせ`

   取得候補: 最大10件。重複・明らかに無関係なものは除外。

2. **記事選別基準**
   - 中小企業・個人事業主向け補助金に関するもの
   - 新規公募・募集開始・制度改正・採択結果いずれか
   - 情報源が公的機関・主要メディア・プレスリリース配信サービス（PR TIMES等）であること

3. **`data/source/subsidy-news.json` 読み込み**
   - ファイルが存在しない場合は `[]` として扱う
   - 既存エントリの `sourceUrl` と重複するものはスキップ

4. **記事生成ルール**
   各記事を以下フォーマットで生成:
   - `title`: 記事タイトル（40字以内）
   - `summary`: 要約（100〜150字）。対象者・補助内容・ポイントを含む
   - `body`: 本文（300〜500字）。以下を含む:
     - 制度の概要・目的
     - 対象（業種・規模・地域）
     - 補助率・上限額（判明している場合）
     - 申請期間・スケジュール
     - 中小企業・個人事業主へのアドバイス1〜2点
   - `category`: 以下から最適なもの1つを選択
     `IT導入補助金` / `ものづくり補助金` / `持続化補助金` / `事業再構築補助金` / `省エネ補助金` / `雇用・人材補助金` / `東京都補助金` / `その他補助金`
   - `tags`: 関連キーワード（3〜5個）
   - `publishedAt`: 記事公開日（YYYY-MM-DD。不明な場合は本日）
   - `sourceLabel`: 出典サイト名
   - `sourceUrl`: 元記事URL
   - `id`: `news-YYYYMMDD-XXX`（日付＋3桁連番）
   - `relatedSubsidySlugs`: `data/generated/subsidies-master.json` から関連補助金slugを0〜3件付与

5. **保存**
   新規記事を配列先頭に追加して `data/source/subsidy-news.json` に保存。

6. **報告**
   - 追加した記事数・タイトル一覧
   - スキップした記事数（重複理由）

## 保存フォーマット

```json
[
  {
    "id": "news-20260516-001",
    "title": "IT導入補助金2026 募集開始",
    "summary": "中小企業・小規模事業者向けITツール導入を支援するIT導入補助金2026の公募が開始。補助率1/2〜3/4、上限450万円。",
    "body": "本文...",
    "category": "IT導入補助金",
    "tags": ["IT導入補助金", "中小企業", "DX", "2026"],
    "publishedAt": "2026-05-16",
    "sourceLabel": "中小企業庁",
    "sourceUrl": "https://...",
    "relatedSubsidySlugs": ["it-donyu-hojo-2026"]
  }
]
```

## 注意

- 情報は正確に。不明な数値・条件は「〜の場合がある」「要確認」と明記
- 出典URLは必ず実在するものを使用（推測・補完禁止）
- 記事は中立的表現。特定サービス・業者の宣伝にならないよう注意
