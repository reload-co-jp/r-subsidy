# 行政書士コメント生成

最新20件の補助金に対して行政書士の視点でコメントを生成し、`data/source/lawyer-comments.json` に保存する。

## 実行手順

1. `data/generated/subsidies-master.json` を読み込む
2. `status !== "closed"` でフィルタし `startDate` または `updatedAt` の降順で上位20件を取得
3. 各補助金の `title`, `overview`, `detail`, `purposes`, `upperLimit`, `subsidizedRate`, `workflow`, `endDate` を参照してコメント生成
4. `data/source/lawyer-comments.json` を読み込み、**既存コメントが存在するslugはスキップ**（手動編集を保護）
5. 新規slugのみコメントを追加して保存

## コメント生成ルール

- **100〜150字**
- 行政書士として申請者に伝える**実務的アドバイス**
- 以下の観点から1〜2点を選んで記述:
  - 申請に必要な書類・証明書
  - 対象要件の確認ポイント（業種・規模・地域）
  - 申請窓口・手続きの流れ
  - 締切・スケジュールに関する注意
  - 補助率・上限額に関する実務上の注意
  - 採択後の報告義務・実績報告
- 語尾は「〜が必要です」「〜に注意してください」「〜を事前に確認してください」など
- 「行政書士コメント」というラベルは不要（表示側で付与済み）
- `_comment` キーは変更しない

## 保存フォーマット

```json
{
  "_comment": "行政書士コメント。キー=slug、値=コメント本文。",
  "example-slug": "【行政書士コメント】申請には〇〇が必要です。事前に要件を確認してください。",
  "actual-slug": "生成したコメント本文"
}
```

## 注意

- `example-slug` キーはサンプルのため変更・削除しない
- コメントが既に存在するslugは上書きしない
- 生成後、追加したslug一覧を報告する
